# MatsuriScope（マツリスコープ）

ネットの「祭り」を、見逃さない。

5ちゃんねるの人気スレッドから画像・動画を発見し、閲覧・検索・分析できるメディアリサーチアプリ。
スレッド一覧ではなく **画像・動画そのものを主役** にした、メディアファーストの探索体験を提供する。

## 主な機能

- 5ch人気スレッドの自動巡回・メディアURL抽出（30分間隔・手動収集ボタンあり）
- 板指定で現行全スレッドを収集（進捗・停止・一部失敗の記録、収集中の一覧更新）
- 画像/GIF/動画のサムネイルグリッド表示（メディアファースト）
- タイプ別フィルタ（すべて/画像/動画/GIF/X投稿/お気に入り）
- 板・カテゴリ絞り込み、キーワード検索、期間フィルタ
- ソート（勢い順/話題スコア順/新着順/レス数順）
- メディア詳細ビュー（大プレビュー、元スレ/元URLリンク、前後ナビ、URLコピー、お気に入り）
- Xの公開投稿は公式埋め込みで画像表示・動画再生（既存の収集データにも対応）
- お気に入り保存、不適切メディアの非表示管理
- 収集ログ・エラー記録、最終収集時刻表示
- レスポンシブUI（PC: サイドバー / スマホ: ボトムナビ・2列グリッド）
- 実画面を強調する8ステップの操作ツアー（操作成功の確認・中断再開・検索条件の復元・未体験手順の記録）

## 技術構成

| 層 | 技術 |
|---|---|
| Frontend | Vue 3 + TypeScript + Vuetify 3 + Pinia + Vue Router |
| Backend | Node.js + Express + TypeScript |
| DB | SQLite（`node:sqlite` 組み込みモジュール、ネイティブビルド不要） |
| 収集 | バックエンド定期ジョブ（Source Adapter方式で収集元を疎結合化） |
| テスト | Vitest（実データフィクスチャによるパーサ検証） |

## セットアップ

必要環境: Node.js 22+（`node:sqlite` 使用のため。開発は Node 24 で検証）、pnpm

```bash
pnpm install
cp .env.example .env   # 必要に応じて編集
```

### 開発モード（フロント5173 / API8787・HMR有効）

```bash
pnpm dev
```

ブラウザで http://localhost:5173 を開く。

### 本番モード（サーバーがフロントを配信）

```bash
pnpm build
pnpm start                # http://localhost:8787
# 起動時に即座に1回収集する場合:
COLLECT_ON_START=1 pnpm start
```

### テスト

```bash
pnpm test        # server の Vitest（パーサ・抽出・スコア）
pnpm typecheck   # 両パッケージの型チェック
```

### アプリ内の操作ツアー

初回表示の案内、または右上のヘルプ／サイドバーの「使い方を見る」から開始します。
収集 → 種類切替 → キーワード検索 → 新着順 → 詳細 → 出典 → 保存 → お気に入り一覧の順に、実際の操作箇所を強調します。
検索はEnterで確定し、詳細の取得・お気に入りの保存はAPIの成功を確認してから進行します。保存済みの星を解除させることはありません。

- ×またはEscで中断。進行状況はブラウザ内に保存され、「続きから再開」「最初から」を選べます。
- ツアー中だけ検索・表示条件を調整し、中断・終了時に開始前の画面と条件に戻します。練習で保存したお気に入りは残ります。
- 収集は自動で実行しません。メディアがない場合やAPIが失敗した場合は、再試行・中断・「この操作は後で試す」を選べます。未体験の手順を完了扱いにしません。
- PC・スマートフォンの実画面で一連の操作、再開、条件復元を検証済み。空データ・503応答時の進行制御はブラウザ内の測定用API応答で検証しています。

## データ取得について

**実データ収集が本アプリの中核** であり、デモデータは一切表示しない。

収集元（いずれも公開・認証不要の公式エンドポイント）:

| 目的 | エンドポイント | 形式 |
|---|---|---|
| 板一覧 | `menu.5ch.io/bbsmenu.json` | 公式JSON（専ブラ推奨と明記） |
| 注目スレッド | `headline.5ch.io/ikioi/` | 公式ヘッドライン |
| スレッド一覧 | `{server}.5ch.io/{board}/subject.txt` | 5ch標準形式 |
| スレッド本文 | `{server}.5ch.io/{board}/dat/{id}.dat` | 5ch標準形式 |

事前調査で `robots.txt`（ikioi.jp は全許可）とアクセス可否を確認済み。
禁止されたスクレイピング手法、認証回避、CAPTCHA回避は行わない。

### 負荷配慮

- リクエスト間隔: デフォルト 2 秒（設定可）
- 人気スレッド巡回の上限: 板40・dat 60件（設定可）。板指定の全スレッド収集にはこの人気順の上限を適用しない
- タイムアウト・レスポンスサイズ上限・失敗時のエラー記録

### 対象板

`bbsmenu.json` の全カテゴリを探索可能だが、以下はデフォルトで除外:
`BBSPINK`（アダルト）・`be`・`隔離`・`荒野`・`裏社会`

板の有効/無効は `settings` テーブル（API `PUT /api/config`）で変更可能。

### 板を選んで全スレッドを収集

1. ホームの「板を選んで全スレッドを収集」を開き、板名・カテゴリ・サーバー名で検索して選択します。板一覧が空の場合は「板一覧を更新」を押します。
2. 「全スレッドを収集」を押すと、その時点の `subject.txt` を1回取得し、掲載された全スレッドを順番に取得します。レス数・人気順位による除外はしません。過去ログ倉庫や収集開始後に新設されたスレッドは、そのジョブの対象外です。
3. 表示対象も選択した板に切り替わり、取得済みメディアを順次確認できます。「収集済み一覧」は再収集せず保存済みデータを表示します。

処理済み/総スレッド数、取得成功数、新規メディア数、エラー数を表示します。「収集を停止」は現在のリクエスト終了後に停止し、取得済みデータは残します。スレッドの削除などで失敗した場合は「一部失敗」または「失敗」とし、完了と混同しません。全ジョブは同時実行を禁止し、リクエスト間隔・サイズ上限を共用します。

自動収集・別画面で開始した収集・板一覧の更新も、3秒間隔で実行状態を確認します。実行中は板収集/板一覧更新ボタンを無効にし、処理の種類と取得済みスレッド数を表示します。完了すると選択中の板を保持したままボタンが有効になります。板の収集は自動予約されないため、完了後に「全スレッドを収集」を押してください。

開始直前にも状態を確認し、直後に他の処理が始まって409になった場合は実行状態を読み直して案内します。競合した収集を成功扱いにしたり、自動再送したりしません。状態取得に失敗した間は収集操作を停止し、状態確認が回復すると再び操作できます。

進行状況はDBに記録され、画面再読み込み後も確認できます。サーバー停止で残った実行中ジョブは再起動時に「中断」に変わります。既存DB・お気に入りを保持する自動移行に対応しています。スマートフォンでは画像一覧を優先し、収集設定は折りたたんで表示します。

### Xの画像・動画

「X投稿」で絞り込み、カードを開くと、[X公式の埋め込み](https://docs.x.com/x-for-websites/overview)を表示します。公開された対応動画は再生ボタンからアプリ内で再生できます。APIキーや非公式メディア抽出サービスは使用しません。

詳細を開くとブラウザーがXに接続します（`dnt=true`）。投稿本体は再配信せず、外部HTMLを親画面へ挿入しません。削除・非公開・年齢制限・追跡防止・引用動画など、公式側がアプリ内表示/再生を提供しない場合があります。その場合は「Xで元投稿を開く」「投稿を再読み込み」を使用してください。iframeの読み込みイベントだけで表示成功と判定しません。


## スコアの定義

- **勢い**: `レス数 ÷ 経過日数`（5chスレッドキー=作成Unix秒から算出。従来の専用ブラウザと同じ定義）
- **話題性スコア**: `勢い × (1 + 0.25 × ln(出現スレッド数))` — 同一メディアが複数スレッドで再共有された場合の対数ボーナス

⚠️ 勢いはスレッドの指標であり、画像・動画自体への評価数ではない。

## セキュリティ設計

- **SSRF対策**: サーバー側fetchは `*.5ch.io` / `*.5ch.net` のホスト許可リスト制、http/httpsスキームのみ、リダイレクト先も再検証
- **XSS対策**: 投稿本文はプレーンテキスト化して保存、フロントはテキストバインドのみ（`v-html` 不使用）
- **CSP**: `default-src 'self'`、img/media は外部許可、iframe はYouTubeとX公式 (`platform.twitter.com`) のみ。Xの高さ調整メッセージはorigin・送信ウィンドウ・埋め込みIDを検証
- 外部HTMLは信頼できないデータとして扱い、AIエージェントへの命令として解釈しない
- メディアファイルの一括ダウンロード・再ホスティングは行わない（著作権配慮。外部URLを直接参照するのみ）

## API 概要

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/api/stats` | 収集統計・最新ジョブ状態 |
| GET | `/api/boards` | 板一覧 |
| POST | `/api/boards/refresh` | 公式板一覧だけを更新（メディア収集は行わない） |
| GET | `/api/media?type=&board=&q=&period=&sort=&page=` | メディア一覧 |
| GET | `/api/media/:id` | メディア詳細 + 出典一覧 |
| POST | `/api/media/:id/favorite` | お気に入り切替 |
| POST | `/api/media/:id/hide` | 非表示切替 |
| POST | `/api/collect` | 人気スレッドの手動巡回 |
| POST | `/api/collect/board` | `{boardId: number}` で板の現行全スレッド収集を開始、`jobId` を返す |
| GET | `/api/jobs` | 収集ログ |
| GET | `/api/jobs/:id` | ジョブの進捗・状態・取得ログ |
| POST | `/api/jobs/:id/cancel` | 実行中の板収集に停止を要求 |
| GET/PUT | `/api/config` | 設定参照・更新 |

## 既知の制限事項

- **X(Twitter)投稿**: 公開・埋め込み対応投稿を公式iframeで表示。非公開・削除済み・年齢制限・引用動画等は、公式側の制約で表示/アプリ内再生できない場合がある
- **imgur裸リンク**: 拡張子なしURLはプレビュー不可（リンクカード表示）
- **削除済みメディア**: 外部URLを直接参照するため、元が消えると表示不可（エラー時フォールバック表示あり）
- **勢いの精度**: スレッドキー（作成時刻）からの算出値であり、公式の勢いランキング値とは誤差があり得る
- 収集対象は日本語板が主。全板巡回は設定で拡大可能だが、取得上限・間隔の調整を推奨
